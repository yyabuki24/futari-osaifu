# ふたりのおさいふ - デプロイ手順（2段階認証つき）

このバージョンから、登録した2つのメールアドレスだけがログインできるようになりました。
ログインには「メールアドレス」＋「認証アプリの6桁コード」の両方が必要です（本格的な2段階認証）。

---

## 手順1〜3（GitHubアップロード・Netlify連携）

これは今までと同じです。前回お渡しした手順書の通りに進めてください。
（GitHubにこのフォルダの中身をアップロード → Netlifyで「Base directory」に `netlify-project` を指定してデプロイ）

## 手順4: 環境変数を設定する（今回の追加作業・重要）

ログインを機能させるために、Netlifyの管理画面で「環境変数」という秘密の設定を5つ追加する必要があります。
**これはGitHubにはアップロードしない、Netlify側だけの設定です。**

1. Netlifyでデプロイしたプロジェクトを開く
2. 左サイドバーの「プロジェクト構成」（Site configuration）をクリック
3. 「Environment variables」（環境変数）という項目を探してクリック
4. 「Add a variable」→「Add a single variable」を選び、以下の5つを1つずつ追加してください

| Key（キー） | Value（値） |
|---|---|
| `ALLOWED_EMAIL_1` | `kurukuruyuzuki610@icloud.com` |
| `TOTP_SECRET_1` | `XEZYUJDQJH5GGPR7TVKQMYN7HYY7JZMQ` |
| `ALLOWED_EMAIL_2` | `yuyayabukijcfl@gmail.com` |
| `TOTP_SECRET_2` | `TSX37LRGCAHXGFZY2GSOZJ5QTU3JB3VB` |
| `SESSION_SECRET` | `Fb29iSGaFU_xZv1GAFQt6g4WyFKBDxvRnXhdFR-gct4` |

5. すべて追加したら、「Deploys」タブから最新のデプロイを「Retry deploy」（再デプロイ）してください
   - 環境変数は、再デプロイしないと反映されません

## 手順5: 認証アプリにコードを登録する（2人それぞれ）

スマホに「認証アプリ」を用意します。すでにお使いのものがあればそれでOKです。

- おすすめ: Google Authenticator（無料・iPhone/Android両方あり）
- iPhoneなら、標準の「パスワード」アプリでも設定可能です

### ゆづさん（kurukuruyuzuki610@icloud.com）

添付の `qr_1.png` を認証アプリの「＋」→「QRコードをスキャン」で読み込んでください。
読み込むと「FutariOsaifu」という項目が追加され、6桁のコードが表示されるようになります。

### ゆうやさん（yuyayabukijcfl@gmail.com）

添付の `qr_2.png` を同じように読み込んでください。

**QRコードが読み込めない場合**は、認証アプリの「手動で入力」を選び、上の表の `TOTP_SECRET_1` または `TOTP_SECRET_2` の値を「キー」として入力すれば同じように登録できます。

## 手順6: ログインする

1. サイトのURLを開く
2. 「メールアドレス」に自分のメールアドレスを入力
3. 「認証アプリの6桁コード」に、認証アプリに表示されている今の6桁の数字を入力
   - このコードは30秒ごとに変わります。古いコードだとログインできないので、表示されている最新の数字を使ってください
4. 「ログイン」をタップ

一度ログインすると、そのスマホ・ブラウザでは30日間ログインしたままになります（毎回コードを入れる必要はありません）。

---

## 大事な注意

- `qr_1.png` / `qr_2.png` と、上の表にある `TOTP_SECRET_1` / `TOTP_SECRET_2` の値は、**GitHubにはアップロードしないでください**。これを知っている人は誰でもログインできてしまいます。
- この2つのQR画像・値は、2人だけで大切に保管してください（スクリーンショットを送り合うのはOKですが、他の人に見せないように）。

---

## 困ったときは

- ログインできない → コードの入力が古くないか（30秒以内に変わります）、メールアドレスのスペルミスがないか確認してください
- 「このメールアドレスは登録されていません」と出る → 環境変数の `ALLOWED_EMAIL_1` / `ALLOWED_EMAIL_2` のスペルを確認してください
- 環境変数を設定したのに反映されない → 「Retry deploy」で再デプロイしてください
- それでもうまくいかない場合は、エラーメッセージをそのままClaudeに伝えてください
